1. Executive Summary

Quicky is a modern dating app designed for fast, authentic connections
with a premium, playful experience. It combines classic swipe matching
with a unique disappearing media feature called "Quicky" (inspired by
Snapchat), a points-based engagement system (Quicky Score), exclusive
premium games (Truth or Dare and more), and strong visibility advantages
for paid users.

The product prioritizes premium design language (dark elegant UI, smooth
micro-interactions, high-quality photography presentation) while
delivering clear, measurable advantages for Premium subscribers: higher
match rates, unlimited engagement tools, exclusive games, and priority
placement in discovery.

This PRD is written so engineering can begin implementation immediately.
Every major feature includes user stories, acceptance criteria, data
considerations, and interaction details.

2. Product Vision & Goals

Vision

Make dating feel light, fun, and high-signal. Users should be able to go
from "interesting profile" to "playful conversation" in seconds, while
Premium users feel clearly rewarded with better visibility, more tools,
and exclusive social play.

Primary Goals

-   High daily engagement through Quicky media + games + streaks

-   Clear free-to-premium conversion driven by tangible advantages
    (visibility, games, insights)

-   Premium design that feels exclusive and modern (not generic
    dating-app UI)

-   Safe, moderated environment with strong reporting and verification
    tools

-   Measurable connection quality: conversations that actually start and
    continue

3. Target Users

-   Primary: Ages 18–35, smartphone-native, value visual communication
    and fun over long forms

-   Secondary: Ages 35–45 looking for efficient, high-quality matching
    with less noise

-   Psychographics: Enjoy Snapchat-style media, games, light competition
    (scores/streaks), and clear status signals

-   Willing to pay for visibility, exclusivity, and better tools once
    they experience the free core

5. Core Features — Free Tier

These features form the complete free experience. Users can discover,
match, chat, and send limited Quickies.

5.1 Onboarding & Account

-   Phone number + OTP verification (primary)

-   Optional social login (Apple, Google) after phone verification

-   Age gate (18+) with date-of-birth

-   Photo upload (minimum 2, maximum 6) with face-detection prompt

-   Basic profile: name, age, gender, looking-for, bio (max 300 chars),
    location (city-level)

-   Interest tags (select up to 8 from curated list + custom)

-   Optional voice intro (15-second audio clip)

5.2 Discovery & Matching

-   Card-based discovery feed (swipe right = Like, left = Pass, up =
    Super Like — limited)

-   Daily Like limit for free users (e.g., 50 likes / day —
    configurable)

-   1 Super Like per day (free)

-   Basic filters: age range, distance, gender preference

-   Match occurs only on mutual Like / Super Like

-   Match notification + match screen with both photos and "Send a
    Quicky" CTA

-   Rewind last swipe (1 per day free)

5.3 Profile

-   Public profile view: photos (carousel), bio, interests, Quicky Score
    badge, verification status

-   Photo order management + primary photo selection

-   Optional prompts ("My ideal Sunday…", "Two truths and a lie…") —
    free users get 1 prompt slot

-   Quicky Score displayed prominently (see Section 8)

5.4 Chat (Matched Users Only)

-   Text messaging with typing indicators

-   Photo & short video sharing (persistent, not disappearing)

-   Emoji reactions on messages

-   Quicky button (disappearing media) — limited daily sends for free
    users

-   Unmatch / Block / Report actions

-   Message request expiry: unmatched chats auto-archive after 7 days of
    inactivity (configurable)

5.5 Safety Basics (Free)

-   In-app reporting with categories + optional screenshot

-   Block user (removes match + prevents future discovery)

-   Photo verification badge (selfie + live challenge) — available to
    all

-   Safety center with tips and emergency resources

6. Premium Features & Advantages

Premium is the core monetization and differentiation layer. Premium
users receive significantly higher connection probability, exclusive
tools, and status.

6.1 Visibility & Connection Boost (Core Advantage)

This is the strongest selling point. Premium users get algorithmically
preferential treatment:

-   Priority Placement: Premium profiles appear higher and more
    frequently in free users' discovery queues

-   Boost Multiplier: Active Premium users receive a rolling "Boost"
    that multiplies their visibility score (e.g., 3×–5× for 30–60
    minutes, or continuous soft boost)

-   Like Priority: When a Premium user Likes someone, that Like is
    ranked higher in the recipient's "Likes You" stack

-   Daily Match Soft Cap Raised: Free users may hit soft daily match
    limits; Premium has higher or no soft cap

-   See Who Liked You: Full list of people who Liked / Super Liked the
    user (free users see blurred previews only)

6.2 Unlimited & Enhanced Engagement

-   Unlimited Likes (no daily cap)

-   5 Super Likes per day (vs 1 free)

-   Unlimited Rewinds

-   Unlimited Quicky sends (free users limited, e.g., 5–10 per day)

-   Advanced Filters: height, education, lifestyle habits,
    verified-only, recently active, interest overlap

-   Passport / Travel Mode: Change location to any city worldwide for
    discovery

6.3 Chat & Social Premium Perks

-   Read receipts on messages

-   Typing indicators enhanced + last-seen (optional privacy toggle)

-   Exclusive stickers & animated reactions

-   Custom chat themes / bubbles

-   Priority customer support

6.4 Profile & Status

-   Premium badge on profile and in chat

-   Up to 3 profile prompts (vs 1 free)

-   Profile Insights: views, like rate, top interests that attract likes
    (anonymized analytics)

-   Incognito Mode: Browse without appearing in "Recently Active" or
    recent viewers

-   Hide age or distance optionally

6.5 Exclusive Games (Premium Only)

See full details in Section 9. Games are a major Premium differentiator
and retention driver.

-   Truth or Dare (text + optional photo/video responses)

-   Never Have I Ever

-   Would You Rather

-   Icebreaker Roulette

-   Custom game creation (Premium+ tier optional)

7. Connection Boost System (Detailed)

The Connection Boost is the algorithmic heart of Premium value.
Implementation notes for ranking:

Visibility Score Components

1.  Base Score: Recency of activity + profile completeness + photo
    quality signals

2.  Premium Multiplier: Continuous soft boost (e.g., ×1.8–×2.5) +
    optional timed Boosts (×5 for 30 min)

3.  Engagement Score: Quicky Score contribution, reply rate, positive
    reports inverse

4.  Mutual Interest Signals: Shared tags, similar age band, distance

5.  Freshness: New Premium users get a temporary "New & Boosted"
    placement for first 24–48h

Engineering note: Maintain a ranked candidate queue per user. When
serving discovery cards, interleave Premium candidates at higher
frequency while still showing organic free users to keep the marketplace
healthy.

8. Quicky Feature (Signature Feature)

Quicky is a Snapchat-style disappearing photo/video message available
only inside matched chats. It drives daily opens, creates urgency, and
feeds the Quicky Score system.

8.1 Core Behavior

-   User opens camera or gallery inside chat → captures/selects photo or
    short video (max 10–15 seconds)

-   Optional text caption (short)

-   User sets view duration: 3s / 5s / 8s / 10s (default 5s)

-   Send → recipient receives push + in-chat Quicky bubble (distinct
    visual: glowing border / camera icon)

-   On open: full-screen view, timer countdown, no pause, no save by
    default

-   After timer ends or user closes: media is deleted from client and
    marked consumed on server

-   Screenshot / screen-record detection: notify sender (best-effort,
    platform limitations apply)

-   Replay: 1 free replay per Quicky for both parties (optional design
    choice); additional replays Premium-only

8.2 Quicky Score (like Snap Score)

Every user has a visible Quicky Score on their profile. It is a
long-term engagement metric.

Point Rules (suggested starting values)

-   +1 for every Quicky sent

-   +1 for every Quicky opened/received

-   +2 for mutual Quicky exchange within 24h (both sent)

-   +5 for maintaining a 3-day Quicky streak with the same match

-   +10 for 7-day streak milestones

-   Score never decreases (or decreases only on major policy violations)

Display: Large number on profile + small badge in chat list. Optional
tier badges (Bronze / Silver / Gold / Platinum Quicky) based on score
thresholds.

Streaks: Show fire emoji + day count next to chat when a Quicky streak
is active. Broken streaks reset the counter but keep total score.

8.3 Limits & Premium Differentiation

Free: 5–10 Quickies per day (server-enforced). Premium: Unlimited. This
creates a natural upgrade moment when a user is mid-conversation and
hits the limit.

9. Game Features (Premium)

Games live inside matched chats (and optionally a "Play" tab for
discovering game-ready Premium users). They are designed to lower the
barrier to conversation and increase session time.

9.1 Truth or Dare

-   Either user can start a Truth or Dare session from the chat action
    menu

-   Chooser picks "Truth" or "Dare" for the other person

-   System serves a random prompt from curated decks (Flirty, Deep,
    Funny, Spicy — with content filters)

-   Answer via text, or optionally via a Quicky (photo/video) for higher
    engagement

-   Skip / Pass allowed with cooldown; custom Truth/Dare submission
    (moderated)

-   Session history kept in chat for reference

9.2 Additional Games

-   Never Have I Ever: Card-based, both answer Yes/No, reveal
    simultaneously, track score

-   Would You Rather: Two options, both choose, then reveal + discuss

-   Icebreaker Roulette: Spin for a random deep or fun question; answer
    in chat or Quicky

-   Two Truths and a Lie: User submits 3 statements; match guesses the
    lie

9.3 Game Technical Notes

-   All game state stored per match conversation

-   Content decks versioned and remote-configurable (no app update
    needed for new prompts)

-   NSFW / intensity filters based on user preference and mutual consent
    settings

-   Premium gate: Non-premium users see a locked "Unlock Games with
    Premium" upsell when they try to start

10. Supporting Systems

10.1 Notifications

-   New Match, New Like (Premium), New Message, New Quicky, Streak
    reminder, Game turn, Boost ending soon

-   Smart quiet hours + preference center

10.2 Monetization

-   Subscription: Weekly / Monthly / 3-Month / Annual (heavy discount on
    longer plans)

-   Consumables: Extra Super Likes packs, one-time Boosts (for free
    users too), extra Quicky packs

-   Optional Premium+ tier later: exclusive games, custom profile
    frames, higher Boost multipliers

-   Paywalls placed at natural friction points: like limit, Quicky
    limit, "See Who Liked You", Games, Advanced Filters

10.3 Moderation & Trust

-   Automated photo scanning (nudity, spam, underage detection via
    third-party or internal models)

-   Text moderation on bios and messages (toxicity, solicitation)

-   Human review queue for reports

-   Shadowban / temporary lock / permanent ban escalation paths

-   Photo verification as trust signal (boosts ranking slightly even for
    free users)

11. Technical Recommendations (Start Coding)

Suggested Stack

-   Mobile: React Native (Expo) or Flutter for cross-platform speed;
    native modules for camera & haptics

-   Backend: Node.js (NestJS) or Go + PostgreSQL + Redis

-   Real-time: WebSockets (Socket.IO or native) or Supabase Realtime /
    Firebase for chat & presence

-   Media: S3-compatible object storage + CDN; signed short-lived URLs
    for Quickies

-   Auth: Phone OTP (Twilio / MessageBird / Firebase Auth) + JWT /
    session tokens

-   Push: FCM + APNs

-   Payments: RevenueCat or native StoreKit / Play Billing + webhook
    reconciliation

-   Analytics: Mixpanel / Amplitude + custom event taxonomy for funnel &
    retention

Key Data Entities (High-Level)

-   User (id, phone, profile fields, subscription_status, quicky_score,
    last_active…)

-   Photo / MediaAsset

-   Swipe / Like (from_user, to_user, type: like|superlike|pass,
    created_at)

-   Match (user_a, user_b, matched_at, status)

-   Message (match_id, sender, type: text|image|video|quicky|system,
    payload, expires_at for Quicky)

-   QuickyView / QuickyEvent (for scoring & screenshot flags)

-   GameSession + GameTurn

-   Subscription + Purchase

-   Report / Block

12. Key User Flows (Implementation Guide)

12.1 First-Time Onboarding

1.  Splash → Phone entry → OTP → Age DOB → Gender & Looking For → Photos
    (min 2) → Bio & Interests → Optional voice → Discovery tutorial →
    First cards

12.2 Matching → First Quicky

2.  Mutual Like → Match celebration screen → "Send a Quicky" primary CTA
    or "Say hi" → Camera / gallery → Set duration → Send → Recipient
    notification → Open → Timer → Score update + streak start

12.3 Premium Upsell Moments

3.  Hit daily Like limit → soft paywall with "See who already likes you"
    teaser

4.  Hit Quicky limit mid-chat → contextual upgrade sheet

5.  Tap locked Games icon → full Premium benefits modal

6.  Blurred "Likes You" list → unlock CTA

13. UI/UX Guidelines — Premium Design

-   Dark-mode first. Light mode supported but secondary.

-   Large, high-quality photo cards with subtle parallax or depth on
    swipe

-   Quicky send/open: full-screen immersive, haptic on open, satisfying
    progress ring

-   Score and streak celebrations: confetti / glow / subtle particle
    effects (not childish)

-   Premium surfaces use gold/lavender accents and refined iconography

-   Empty states and error states are helpful and on-brand, never
    generic

-   Accessibility: Dynamic type, sufficient contrast, VoiceOver/TalkBack
    labels on all actions

14. Success Metrics & KPIs
